    What NU7 changed

    For integrators. If you only use a wallet, the check above is all you need.

    1. Version 4 transactions are rejectedTransparent-only ones included (ZIP 2003). Build v5 or v6.
    2. New branch ID 0x77190AD9v5 and v6 signatures commit to it, so a signer with old constants fails even if it already builds v5.
    3. A block every 25 secondsDown from 75 (ZIP 218). The same number of confirmations now takes a third of the time.
    4. Sprout funds are stuckSprout can only be spent in a v4 transaction, which is no longer valid.

    Source: ZIP 259. Zebra 7.0.0 is the node release that activated NU7.
